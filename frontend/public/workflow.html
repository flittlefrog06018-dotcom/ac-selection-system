為何打造此系統？傳統作業痛點 (Pain Points)

📐
專業繪圖軟體綁定門檻高 傳統痛點

過往計算空間面積，同仁必須具備 AutoCAD 專業技能並安裝高昂授權軟體。若客戶僅提供平面圖片 (JPG/PNG) 或 PDF 圖檔，常須耗費數小時手動描點量測或用比例尺手算，門檻極高且外勤業務無法就地作業。

🤯
空調負荷試算繁瑣且易算錯 傳統痛點

各空間因西曬、頂樓、大片玻璃或高熱源需微調不同熱負荷基準（500 ~ 900 kcal/hr/坪）。手動換算平方公尺、坪數、總冷房需求 (kW / kcal/hr) 過程冗長，容易因計算機失誤導致配機噸數不足或過度超配。

📚
全產品規格繁雜，配對極度耗時 傳統痛點

大金涵蓋家用 (RA)、商用 (SA)、VRV 頂級多聯，上百種室內外機型號。不同系列具備不同供電規格 (單相 220V / 三相 380V)、能力指數、連結率限制（50%~130%）與風扇型式，手動查閱厚重目錄極易搭配錯誤。

📑
配件與基板漏選、報價重複謄寫 傳統痛點

當業主指定「APP 遠端控制」或「中央集中控制」時，各室內機型號對應之專用轉接小P板 (如 BRP067A42)、APP卡 (如 BRP072C42) 或集控基板 (如 KRP928BB2S) 極易遺漏，且須手動謄寫 Excel 官方底稿，耗費大量工時。

核心架構與技術克服 (Technical Highlights)

⚡
雙軌幾何影像引擎

整合 **漆桶洪泛發散 (Flood Fill)**、**矩形拉框**、**多邊形 (PLine)** 與 **門寬基準比例尺校正**。系統直接在一般網頁照片上演算真實世界幾何邊界，**完全不依賴 CAD 軟體**即可高精度換算真實面積與坪數。

🧠
零死背動態空間配對

嚴格遵守無硬編碼原則，透過空間幾何座標距離與拓撲鄰近性，動態將辨識出的房間名稱（如客廳、主臥）與面積框選連鎖匹配，自動過濾非空調管道間雜訊，維持高強健度。

🛡️
前後端雙軌容錯匯出

後端 Python openpyxl 與前端 ExcelJS 採用一致之資料字典拓撲。即便在純靜態雲端環境 (如 Vercel) 離線或逾時，前端備援引擎亦能無縫產出格式 100% 對齊的 5 大工作表專業 Excel 選機底稿。

雲端環境 (Vercel) 與 Antigravity 使用限制說明

層面 / 模組 運行限制與特性 系統應對策略與克服方案
雲端靜態託管 (Vercel) Vercel 預設為純前端靜態環境，無法常駐執行 Python 後端運算程序，所有 `/api` 請求在純靜態下會直接由前端路由承接。 建構「前端 ExcelJS 完整備援拓撲引擎」，將設備資料庫全數打包至前端 JSON，不依賴後端即可產出完整 5 大工作表。
圖面畫質與比例標定 照片可能存在透視變形、解析度過低、或未標記尺寸之草圖，純演算法難以百分之百推敲絕對比例。 開發「門寬 / 參考尺寸一鍵標定桿」，使用者只要點擊已知寬度（如 90cm 房門），系統即秒級鎖定像素/米換算比率。
複雜開放空間格局 大坪數豪宅常出現客廳、餐廳、玄關連通無實體隔間牆，自動漆桶會一次填滿過大面積。 提供「劃線任意分割」與「多邊形 PLine」手動畫定工具，可隨意虛擬切分客廳、走道與餐廳個別負擔之空調配額。
離線資料同步 (Antigravity) 本機開發與雲端正式站需確保演算法核心與產出樣式完全一致，避免版本漂移。 透過自動化 Build 流程（Vite Rollup Bundle + 跨目錄同步腳本）與 Git Tag 雙軌機制，保證線上站點即時獲得最新版次。

AI 智慧選機標準操作流程 (5-Step Workflow)

01

第一步：載入平面圖面與校正比例尺

拖曳或上傳任何建築平面圖（JPG、PNG 或 PDF 截圖）。點選「1. 參考尺寸」，在圖面上點選一段已知長度的門寬（如 90cm）或標註尺寸，系統立即自動計算全圖像素比，完成空間幾何座標初始化。

免裝 AutoCAD 支援手機照片 自適應高解析縮放
02

第二步：空間框選與面積/坪數自動運算

使用「2. 漆桶發散」無視家具線條點擊房間內部自動辨識邊界，或使用「3. 矩形拉框」、「4. 多邊形 PLine」精準圈出空間。系統即時換算平方公尺 (㎡) 與坪數 (P)，並列入下方動態負載表格中。

漆桶智能穿透 面積雙指標高對比標籤 開放空間可劃線切分
03

第三步：冷房熱負荷估算與室內機智慧配置

系統依據各空間性質自動帶入建議之每坪熱負荷基準（一般 500 kcal/hr，頂樓/西曬可一鍵提升至 650~750 kcal/hr）。全自動計算總熱需求 (kW / kcal)，並由大金全機型資料庫秒級比對出最合適之室內機型號與台數。

RA/SA/VRV 規格一鍵切換 冷暖/冷專自動推薦 壁掛/吊隱式動態鎖定
04

第四步：室外機智慧配對與單雙聯分組

系統支援「單台 1對1 自動配對」、「家用多聯 (Multi) 智慧合併」與「VRV 集中大系統」。可透過右鍵快捷選單「將勾選空間併入同一台室外機」，自動計算室內外機總容量指數與連結率防呆（如 100%~130%），確保冷房能力充沛。

商用 SA 電源防呆鎖定 VRV 併機縱向跨列合併 冷媒分歧頭自動精算
05

第五步：決定控制需求與一鍵匯出官方底稿 (.xlsx)

選擇全案控制方案：一般遙控器、**APP 遠端控制**、或**集中控制器**。點擊「立即匯出完整選機與報價表」，系統自動生成包含 5 大工作表的官方 Excel 活頁簿：選機表、設備報價單（精準附帶小P板與APP控制卡）、設備統計總表、系統套數拓撲、D3-NET通訊分析。

官方 Excel 5 大分頁全開 報價單取消項次首欄為系統類別 公式全自動連動

系統所驅動之 AI 功能與 AI Agent 程式架構

👁️
多模態視覺感知與 OCR Agent Perception

主要職責：自主掃描建築平面圖，辨識空間文字標註（如「客廳」、「主臥」、「次臥」、「書房」）、門窗線條符號及圖面自帶之尺寸標籤。
底層技術與模型：結合 Google Gemini 1.5 Pro / Flash 多模態視覺神經網絡、PaddleOCR 輕量光學文字模型與 OpenCV 自適應二值化 (Adaptive Thresholding) 影像預處理層。

📐
空間幾何拓撲計算 Agent Geometry

主要職責：解決「免裝 CAD 即時算量」關鍵難題。執行漆桶洪泛發散 (Flood Fill)、Canny 邊界尋跡、多邊形頂點閉合檢驗，並透過門寬基準尺將像素幾何轉換為物理世界的平方公尺 (㎡) 與坪數。
底層技術與模型：雙軌向量演算法、Connected Components 連通區域標記、Canvas 2D / WebGL 像素陣列並行運算。

🧠
空調熱負荷與大金型錄 Reasoning Agent Domain Logic

主要職責：根據空間類型與熱源特性自動指派建議每坪負荷基準（500~900 kcal/hr/坪），計算總需求能力 (kW)。連鎖檢索大金全產品庫 (EQUIPMENT_Data)，自動匹配最佳室內機型號、電源防呆與風扇型式。
底層技術與模型：專家知識圖譜 (Domain Rule Engine)、思維鏈推論 (Chain-of-Thought)、大金規格多維度交叉索引矩陣。

🔌
系統群組拓撲與控制配件 Agent Synthesis

主要職責：自動評估 VRV 系統連結率 (50%~130%) 與冷媒分歧頭管徑。當使用者選擇「APP 遠端控制」或「集中控制」時，精準推導各室內機所需的轉接小P板 (如 BRP067A42)、APP卡 (如 BRP072C42) 或集控基板 (如 KRP928BB2S)。
底層技術與模型：圖論樹狀拓撲演算法 (Tree Topology Engine)、配件相依性約束求解器 (Constraint Solver)。
