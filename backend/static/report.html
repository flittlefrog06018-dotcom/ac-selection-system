PART 1

為何要做？傳統空調選機作業的 4 大致命痛點

📐
痛點一：繪圖軟體授權與專業門檻高 痛點

過往計算室內空間面積，必須具備 AutoCAD 專業技能並安裝昂貴授權軟體。若客戶僅提供手機照片（JPG/PNG）或 PDF 圖面，業務或工程師需耗費數小時手動拉比例尺或徒手測量，外勤無法就地報價。

🧮
痛點二：冷房熱負荷試算繁複且易出錯 痛點

各房間因西曬、頂樓、挑高或大面落地窗，需給予不同每坪熱負荷基準（500 ~ 900 kcal/hr/坪）。從平方公尺換算坪數、再乘算熱負荷與 kW 過程冗長，容易因計算機人為按錯導致噸數選配不足或過度超配。

📚
痛點三：大金產品線龐雜，選型極耗時 痛點

大金涵蓋家用 (RA)、商用 (SA)、VRV 頂級多聯上百種室內外機。各系列具備不同供電（單相220V/三相380V）、容量指數、連接率上限（如 2MXM/3MXM 官方嚴格限制）及風扇型式，人工翻閱厚重型錄極易搭錯。

💸
痛點四：控制配件與基板漏估造成虧損 痛點

當業主需求「手機 APP 遠端控制」或「中央集中控制」時，各室內機型號對應之專用轉接小 P 板（如 BRP067A42）、APP 控制卡（如 BRP072C42）或集控基板極易漏選；且手動謄寫 Excel 官方底稿耗損大量高薪工時。

PART 2

實際操作演練流程：5 步極簡閉環 (Live Demo Flow)

01

步驟一：載入圖面與一鍵校正比例尺

拖曳或上傳任何格局平面圖（手機拍攝之 JPG、PNG 或 PDF 截圖）。點擊「參考尺寸」，在圖面上選取一段已知長度（如 90cm 標準房門或 CAD 標註尺），系統立即自動計算全圖像素/米（px/m）真實換算比率。

免裝 AutoCAD 支援手機拍照 像素精準校正
02

步驟二：空間框選與面積/坪數自動即時換算

使用「漆桶發散」穿透家具線條點擊房間內部自動辨識邊界，或使用「矩形拉框」、「多邊形 (PLine)」圈出空間。系統即時換算平方公尺（㎡）與坪數（P），並列入下方動態負載運算清冊中，開放空間亦可隨意劃線虛擬分割。

漆桶智慧發散 多邊形精確圈選 坪數與㎡毫秒計算
03

步驟三：智慧負荷計算與最適室內機自動推薦

系統依照各空間特性自動帶入每坪建議負荷（一般 500 kcal/hr，頂樓/西曬可一鍵拉升），全自動推導總熱需求（kW / kcal），並連鎖檢索大金全產品資料庫，秒級自動匹配出能力最契合之室內機型號與台數。

RA / SA / VRV 即時切換 冷房能力防呆計算 壁掛/吊隱式動態鎖定
04

步驟四：室外機智慧配對與多聯 / VRV 系統群組化

支援「單台 1對1 自動配對」、「家用多聯 (Multi) 智慧合併」與「VRV 大系統集中主機」。勾選多個空間點擊「併入同一台室外機」，系統自動遵循大金官方最大允許連接能力，並主動防呆警示超配或欠配。

單機/多聯/VRV自由組合 官方連接率 100%~130% 檢驗 外機容量欠配/超配自動警告
05

步驟五：控制配件自動精算與一鍵匯出大金官方 Excel

勾選控制需求（一般遙控、手機 APP 雲端控制、集中控制器、伶俐智能管理）。點擊「立即匯出選機表」，系統即刻產出具備樣式與公式的官方 Excel 活頁簿：包含【選機表】、【設備報價單】（室外機置頂升冪排序、精確補齊小P板與配件金額）與【系統套數】（標註標準液氣配管徑 Ø6.4/Ø9.5、Ø6.4/Ø12.7）。

分頁白名單自動隱藏非必要分頁 室外機置頂與容量升冪排序 配件金額與小計公式連動
PART 3

技術架構解析：Google Antigravity 與各程式語言職責

AI 中樞 Google Antigravity 多代理人架構 (Multi-Agent)

專案核心引擎：本系統開發與維運全程運用 Google Antigravity，其扮演了系統架構師、雙軌代碼重構引擎與自動化品質守門員角色。

• 規劃與規範防護：遵循自定義之 Track A 辨識原則（嚴禁硬編碼房間名或靜態 Mock 陣列，必須純演算法動態求值）。
• 自動化驗證與回歸：在每次更新大金配管與選機邏輯時，自動啟動 headless Python 執行驗證腳本，確保匯出試算表公式與資料庫 100% 對齊。

後端主力 Python 在本專案中運用在哪裡？

核心運算與後台微服務 (FastAPI + Python 3.11)：
• 幾何與空間分析：使用 OpenCV (cv2) 與 NumPy 進行圖面自適應二值化、輪廓檢測與空間連通域（Connected Components）多邊形逼近。
• 報表動態渲染引擎：使用 openpyxl 載入大金官方範本，執行縱向跨列合併、公式注入、樣式套用及工作表白名單過濾。
• VRV 樹狀配管計算器：以純 Python 實作 DaikinVRVPipingEngine，遵循大金官方手冊動態遞迴推導主幹管、次幹管與分歧頭型號。

影像辨識 圖面辨識是透過什麼 AI 與演算法分析？

零 CAD 依賴的次世代視覺解構技術：

1. 向量輪廓尋跡 (Contour Tracing)：利用 OpenCV 針對圖面線條進行 Sobel 梯度檢驗與 Canny 邊界尋跡，將圖像像素矩陣轉化為可計算之向量幾何頂點。
2. OCR 文字辨識與坐標匹配：透過光學文字識別（OCR）動態擷取圖面文字標籤（如「客廳」、「主臥」）的 Bounding Box 坐標。
3. 幾何鄰近性演算法 (Spatial Proximity Matching)：以歐氏距離矩陣計算空間文字中心點與幾何封閉多邊形的重疊度，實現「零硬編碼」的動態房間名稱與面積綁定。

前端表現 JavaScript / React 18 / ExcelJS 雙軌備援

極速響應前端與雲端容錯機制：

• React 18 + Vite：打造流暢、低延遲的現代化操作介面，支援圖面縮放（Pan/Zoom）、自適應畫布與右鍵快捷選單。
• HTML5 Canvas 2D：在毫秒級別內渲染多邊形標記、面積數值與紅框邊界。
• ExcelJS 純前端離線備援：將設備資料庫打包至前端，在雲端無 Python 容器（如 Vercel 靜態環境）下，前端依然能 100% 獨立產出官方級 Excel 報表。

效益對比：傳統人工作業 vs. AI 智慧選機系統

評估維度 傳統人工作業模式 本系統 AI 智慧選機模式
作業時間 一案平均需耗費 2 ~ 4 小時（開圖、量尺寸、查型錄、手打 Excel）。 全流程僅需 3 ~ 5 分鐘，效率巨幅提升 90% 以上。
軟體工具要求 需安裝專業 AutoCAD 軟體與昂貴授權，需具備製圖能力。 零 CAD 依賴，使用一般瀏覽器（Chrome/Safari）即可跨平台作業。
選型與計算精準度 容易因手按計算機漏算熱負荷，或選錯室內外機連接率。 演算法嚴格遵循大金官方規格手冊，自動防呆超配與欠配。
配件與報價完整度 APP 雲端控制卡、小 P 板、VRV 分歧頭經常遺漏，導致報價短少虧損。 系統自動關聯清點控制配件與小 P 板，金額公式自動計入總價。
配管管徑規範 需手動查閱配管手冊，容易記錯 2分/3分 與 2分/4分 規格。 自動依照機型級數標註精確液氣管徑（如 20~36級標註 Ø6.4/Ø9.5，40~60級標註 Ø6.4/Ø12.7）。
